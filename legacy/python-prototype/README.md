# Historical local Python prototype

These files preserve an earlier local BotCalc prototype that had not been tracked
in Git. They are retained as a reference alongside the current TypeScript engine.
The preservation import does not replace the current application or reconcile the
two implementations.

The three Python modules passed syntax parsing and parts_db.json parsed successfully
on November 12, 2026. The Streamlit application and database behavior were not run as
part of this import. Dependencies and runtime assumptions still need review before
reusing this prototype.

The original local workspace was also captured in a checksum-verified archive,
including its Git metadata. No implementation was changed in this preservation copy.
